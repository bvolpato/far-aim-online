# Security policy

FAR/AIM Online is free and open source. Please report suspected security
vulnerabilities privately through **Security → Report a vulnerability** on the
GitHub repository. Do not disclose an unpatched vulnerability in a public issue
or pull request.

Include the affected version or commit, the files or route involved, steps to
reproduce, and the likely impact. Do not include real credentials or private
user data in a report. The maintainers will acknowledge reports and coordinate
a fix and disclosure with the reporter. There is no guaranteed response time.

For ordinary bugs, use GitHub Issues. For a proposed fix, open a pull request
after reviewing [the contribution guidance](CONTRIBUTING.md).
